= Slack Reactions Notifier

A simple Slack bot that notifies you when someone adds a reaction to your message.

== Features
- Captures `reaction_added` events.
- Notifies you via DM when someone reacts to your messages.
- Self-reaction debug mode.
- Configurable logging levels.
- Pydantic-based configuration.
- Dockerized setup.

== Configuration
The application is configured via environment variables or a `.env` file located in the project root (parent of the `app/` directory).

[cols="1,2,1"]
|===
| Variable | Description | Default

| SLACK_BOT_TOKEN | Your Slack Bot User OAuth Token (`xoxb-...`) | Required
| SLACK_APP_TOKEN | Your Slack App-Level Token (`xapp-...`) | Required
| MY_SLACK_ID | Your Slack Member ID (e.g., `U12345678`) | Required
| LOGGING_LEVEL | Logging level (DEBUG, INFO, WARNING, etc.) | INFO
|===

=== Configuration Methods
The application supports two primary configuration methods:

1. **Build-time `.env` file**:
You can place a `.env` file in the project root before building the Docker image. The `Dockerfile` copies this file into the `/app` directory inside the container. This method is convenient for stable environments.

2. **Runtime Environment Variables**:
You can build the container with an empty or missing `.env` file and provide all necessary settings at runtime. Environment variables take precedence over values in the `.env` file. This is the recommended way to handle sensitive tokens.

Example of a startup script (`run_notifier.sh`) using runtime variables:

[source,bash]
----
#!/bin/bash
docker run -d \
  --name slack-reactions-notifier \
  -e SLACK_BOT_TOKEN="xoxb-your-bot-token" \
  -e SLACK_APP_TOKEN="xapp-your-app-token" \
  -e MY_SLACK_ID="U12345678" \
  -e LOGGING_LEVEL="INFO" \
  slack-reactions-notifier
----

== Installation

=== Using Docker
1. Build the image:
[source,bash]
----
./docker_build.sh
----

2. Run the container:
[source,bash]
----
./docker_run.sh
----

=== Local Development
1. Install dependencies:
[source,bash]
----
pip install -r requirements.txt
----
(Note: It is recommended to use `uv` or `pip` with `pyproject.toml`)

2. Run the application:
[source,bash]
----
python -m app.slack_reaction_notifier
----

== Project Structure
- `app/slack_reaction_notifier.py`: Main entry point.
- `app/config.py`: Configuration management.
- `app/logs/`: Directory for log files.
- `Dockerfile`: Container definition.
- `pyproject.toml`: Project metadata and dependencies.
