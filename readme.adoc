= Slack Reactions Notifier

A simple Slack bot that notifies you when someone adds a reaction to your message.

== Features
- Captures `reaction_added` events.
- Notifies you via DM when someone reacts to your messages.
- Self-reaction debug mode.
- Configurable logging levels.
- Pydantic-based configuration.
- Dockerized setup.

== Configuration
The application is configured via environment variables or a `.env` file located in the project root (parent of the `app/` directory).

[cols="1,2,1"]
|===
| Variable | Description | Default

| SLACK_BOT_TOKEN | Your Slack Bot User OAuth Token (`xoxb-...`) | Required
| SLACK_APP_TOKEN | Your Slack App-Level Token (`xapp-...`) | Required
| MY_SLACK_ID | Your Slack Member ID (e.g., `U12345678`) | Required
| LOGGING_LEVEL | Logging level (DEBUG, INFO, WARNING, etc.) | INFO
| LOGGING_LEVEL_FOR_THIRD_PARTY_LIBS | Logging level for third-party libraries (slack_bolt, etc.) | WARNING
|===

=== Configuration Methods
The application supports two primary configuration methods:

1. **Build-time `.env` file**:
You can place a `.env` file in the project root before building the Docker image. The `Dockerfile` copies this file into the `/app` directory inside the container. This method is convenient for stable environments.

2. **Runtime Environment Variables**:
You can build the container with an empty or missing `.env` file and provide all necessary settings at runtime. Environment variables take precedence over values in the `.env` file. This is the recommended way to handle sensitive tokens.

Example of a startup script (`run_notifier.sh`) using runtime variables:

[source,bash]
----
#!/bin/bash
docker run -d \
  --name slack-reactions-notifier \
  -e SLACK_BOT_TOKEN="xoxb-your-bot-token" \
  -e SLACK_APP_TOKEN="xapp-your-app-token" \
  -e MY_SLACK_ID="U12345678" \
  -e LOGGING_LEVEL="INFO" \
  -e LOGGING_LEVEL_FOR_THIRD_PARTY_LIBS="WARNING" \
  slack-reactions-notifier
----

== Installation

=== Slack Configuration Steps

Follow this hierarchical guide to configure your Slack workspace, enable user interaction, obtain the required environment variables (`SLACK_APP_TOKEN`, `SLACK_BOT_TOKEN`, `MY_SLACK_ID`), and successfully test the script.

. *Creating the App & Obtaining `SLACK_APP_TOKEN`*
  .. Open the Slack Application Management console directly via link:https://api.slack.com/apps[api.slack.com/apps].
  .. Click the *Create New App* button in the top right corner.
  .. Select the *From scratch* option in the pop-up dialog.
  .. Provide your configuration details:
    ... *App Name*: Enter a descriptive name (e.g., `slack-reactions-notifier`).
    ... *Development Slack Workspace*: Select your company's workspace from the dropdown list.
  .. Click the *Create App* button to finalize.
  .. In the left navigation menu under *Settings*, select *Socket Mode*.
  .. Toggle the *Enable Socket Mode* switch to the *ON* position.
  .. In the modal window that appears, enter any token name (e.g., `SocketToken`) and click *Generate*.
  .. Copy the generated string starting with `xapp-...`. Save this as your *`SLACK_APP_TOKEN`*.

. *Configuring Permissions & Messages Tab*
  .. In the left navigation menu under *Features*, select *OAuth & Permissions*.
  .. Scroll down to the *Scopes* section, specifically under *Bot Token Scopes*.
  .. Click the *Add an OAuth Scope* button and assign the following permissions:
    ... `reactions:read` — allows the app to detect emoji reaction events.
    ... `chat:write` — allows the app to send direct messages to your account.
    ... `channels:history` — allows the app to monitor channel history.
  .. In the left navigation menu under *Features*, select *Event Subscriptions*.
  .. Toggle the *Enable Events* switch to the *ON* position.
  .. Scroll down to the *Subscribe to bot events* subsection, click *Add Bot User Event*, and select `reaction_added` from the list.
  .. Click the *Save Changes* button at the bottom of the page (ensure the button is clicked and settings are saved).
  .. In the left navigation menu under *Features*, select *App Home*.
  .. Scroll down to the *Show Tabs* section, locate the *Messages Tab*, and toggle it *ON*.
  .. Check the box for *"Allow users to send Slash commands and messages from the messages tab"*.

. *Installing the App & Obtaining `SLACK_BOT_TOKEN`*
  .. In the left navigation menu under *Settings*, select *Install App*.
  .. Click the green *Install to Workspace* button and authorize the application permissions.
  .. Copy the generated *Bot User OAuth Token* starting with `xoxb-...`. Save this as your *`SLACK_BOT_TOKEN`*.

. *Obtaining Your Personal `MY_SLACK_ID`*
  .. Open your official Slack desktop or mobile application.
  .. Click on your *Profile Picture / Avatar* in the application interface.
  .. Select the *Profile* option from the dropdown menu to open your profile sidebar.
  .. Click the *More (...)* button (three horizontal or vertical dots) inside the profile view.
  .. Click the *Copy member ID* option.
  .. The string starting with `U...` (e.g., `U1234567890`) is now copied to your clipboard. Save this as your *`MY_SLACK_ID`*.

. *Client Refresh & Initial Testing (Crucial Steps)*
  .. *Force Refresh Slack Client*: Open your desktop Slack application and press `Ctrl + R` (Windows) or `Cmd + R` (Mac). This forces Slack to clear its cache and unblock the app's messaging interface.
  .. *Locate the Bot*: In the left sidebar of your Slack client, scroll down to the *Apps* section, click the `+ Add apps` button if necessary, find your `slack-reactions-notifier` application, and open its direct chat.
  .. *Verify Direct Messages*: Send a message directly to the bot inside this chat to verify the text input is fully unlocked.
  .. *Testing the Handler*:
    ... Run your Python script with the configured environment variables.
    ... Post a message inside the bot's direct chat or in a public channel where the bot has been invited via `/invite @slack-reactions-notifier`.
    ... Add an emoji reaction to that message. The handler will capture the event, write formatted logs to the screen and the `logs/` directory, and send a notification back to you.



=== Using Docker
1. Build the image:
[source,bash]
----
./docker_build.sh
----

2. Run the container:
[source,bash]
----
./docker_run.sh
----

=== Local Development
1. Install dependencies:
[source,bash]
----
pip install -r requirements.txt
----
(Note: It is recommended to use `uv` or `pip` with `pyproject.toml`)

2. Run the application:
[source,bash]
----
python -m app.slack_reaction_notifier
----

== Project Structure
- `app/slack_reaction_notifier.py`: Main entry point.
- `app/config.py`: Configuration management.
- `app/logs/`: Directory for log files.
- `Dockerfile`: Container definition.
- `pyproject.toml`: Project metadata and dependencies.
