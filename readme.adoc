= Slack Reactions Notifier

== Description

A simple Slack bot that notifies you when someone adds a reaction to a message in your channels.

NOTE: This app does *not* work out of the box. +
      It's intended for IT professionals or IT enthusiasts. +
      To use it, you need to create your own private application inside your Slack workspace
      and configure it accordingly.
      Docker (podman) is also required, as the app runs in a user-container.
      These are all simple steps, easy for an IT professional,
      and are described in detail below.

=== Features

- Captures `reaction_added` events.
- Notifies you via DM when emoji reactions are detected in your channels.
- .env-based configuration.
- Dockerized.

=== Architecture

This application uses a hybrid architecture.

* It monitors events and reads channels using your personal SLACK_USER_TOKEN +
  (acting with your personal access level)
* But sends direct notifications back to you using the SLACK_BOT_TOKEN +
  to avoid scope restrictions.

=== Dockerization

The application runs exclusively within a Docker container.
Nothing is exposed or mapped anywhere.

=== Logging

Logs are created inside the debug container.
In LOGGING_LEVEL=INFO mode, the log is virtually nonexistent, so the container won't bloat.
In DEBUG mode, every response is logged.

== Configuration

=== Environment variables (.env file)

The application is configured via environment variables in `.env` file
located in the project root (parent of the `app/` directory).
So, initially you may copy it from .env.example to the same dir.

[cols="1,2,1"]
|===
| Variable | Description | Default

| SLACK_APP_TOKEN | Your Slack App-Level Token (`xapp-...`) | Required
| SLACK_USER_TOKEN | Your Slack User OAuth Token (`xoxp-...`) | Required
| SLACK_BOT_TOKEN | Your Slack Bot User OAuth Token (`xoxb-...`) | Required
| MY_SLACK_ID | Your Slack Member ID (e.g., `U12345678`) | Required
| NOTIFY_REACT_ONLY_ON_MY_MESSAGES | If true, notify only about reactions to your messages; otherwise, notify about all reactions | true
| LOGGING_LEVEL | Logging level (DEBUG, INFO, WARNING, etc.) | INFO
| LOGGING_LEVEL_FOR_THIRD_PARTY_LIBS | Logging level for third-party libraries (slack_bolt, etc.) | WARNING
|===

=== Configuration Methods

The application supports two primary configuration methods:

==== Build-time `.env` file (recommended)

You can place a `.env` file in the project root before building the Docker image. +
The `Dockerfile` copies this file into the `/app` directory inside the container. +
This method is convenient for stable environments.

==== Runtime Environment Variables (optional)

You can build the container with an empty or missing `.env` file
and provide all necessary settings at runtime. +

Example of a startup script (`run_notifier.sh`) using runtime variables:

[source,bash]
----
#!/bin/bash
docker run -d \
  --name slack-reactions-notifier \
  -e SLACK_APP_TOKEN="xapp-your-app-token" \
  -e SLACK_USER_TOKEN="xoxp-your-user-token" \
  -e SLACK_BOT_TOKEN="xoxb-your-bot-token" \
  -e MY_SLACK_ID="U12345678" \
  -e NOTIFY_REACT_ONLY_ON_MY_MESSAGES="true" \
  -e LOGGING_LEVEL="INFO" \
  -e LOGGING_LEVEL_FOR_THIRD_PARTY_LIBS="WARNING" \
  slack-reactions-notifier
----

== Installation

=== Slack Setup Guide

This project requires you to create your own private application
inside your Slack workspace.
To protect your corporate credentials and maintain maximum security
without a centralized server, the script runs entirely under your application
and your personal Slack account scopes.
It is recommended to name your application `slack-reactions-notifier` for consistency.
This setup grants the containerized application the exact same channel access level
as you currently have.

==== Configure and install your application.

===== Create your application

. Go to link:https://api.slack.com/apps[api.slack.com/apps] link
  * click *Create an App* -> *Blank app*.
  * Name it `slack-reactions-notifier` (may be another if you wish) and select your workspace.

===== Configure your application

. Go to *Settings* -> *Socket Mode*
  * Check that *Enable Socket Mode* is *ON*.
. Go to *Features* -> *OAuth & Permissions*.
  * Under *User Token Scopes*, add:
    ** `reactions:read` — to detect emoji reaction events.
    ** `channels:history` — to monitor public channel history.
    ** `groups:history` — to monitor private channel history.
  * Under *Bot Token Scopes*, add:
    ** `chat:write` — to send direct messages back to you.
. Go to *Features* -> *Event Subscriptions*
  * toggle *Enable Events* to *ON*.
  * Under *Subscribe to events on behalf of users*
    ** add `reaction_added`
    ** click *Save Changes* at the bottom.
. Go to *Features* -> *App Home*.
  ** Under *Show Tabs*
     *** check that *Messages Tab* is *ON*
     *** check *"Allow users to send Slash commands and messages from the messages tab"*.
. Go to *Features* -> *OAuth & Permissions* -> *Redirect URLs*.
  * Add `http://localhost:51999` and click *Save URLs*.
. Go to *Settings* -> *Install App*
  * click button *Install to [Your Workspace]*, and authorize permissions.
    ** You will see the window with some app properties
       *** if *User OAuth Token* (starting with `xoxp-...`) displayed then
           **** Copy the generated *User OAuth Token* starting with `xoxp-...`.
           **** Save it as `SLACK_USER_TOKEN` in your *.env* file.
       *** Copy the generated *Bot User OAuth Token* starting with `xoxb-...`.
       *** Save it as `SLACK_BOT_TOKEN` in your *.env* file.
. Go to *Settings* -> *Basic Information*
  * Scroll to *App-Level Tokens*
    ** Click on the "Generate Token and Scopes"
       *** In displayed modal window
          **** Enter token name (e.g., token-for-slack-reactions-notifier)
          **** Click Add Scope
               ***** Find and select `connections:write` scope
          **** Click Generate
          **** In displayed modal window
               ***** Copy the token contents
               ***** Paste it into the `SLACK_APP_TOKEN` in your *.env* file.
               ***** Click *Done* to close the modal window.
. Run Interactive Authentication (only if `SLACK_USER_TOKEN` is empty)
  * if you did not fill `SLACK_USER_TOKEN` in the steps above then
    ** Go to *Settings* -> *Basic Information* -> *App Credentials*.
    ** Copy your `Client ID` and `Client Secret` (click *Show*). +
       You will need them for the interactive login script.
    ** Launch the auth script with such command (in one line)
       *** `SLACK_CLIENT_ID="your_client_id_here" SLACK_CLIENT_SECRET="your_client_secret_here" ./run_auth.sh`
       *** Your browser will prompt you to authorize your mirror app. +
           **** Click *Allow*. +
           **** A local success webpage will display your generated +
                ***** `SLACK_USER_TOKEN` (starts with `xoxp-...`)
                ***** `MY_SLACK_ID` (starts with `U...`).
           **** Copy them into your production `.env` file and close the browser.

==== Step 5: Client Refresh & Verification

. **Fill `MY_SLACK_ID` (if empty) in the `.env`**
  * if you did not fill `MY_SLACK_ID` in the steps above then
    ** Click on your avatar in the corner of the slack app window +
       (usually bottom left or top right, depending on the version of the interface).
    ** Select Profile from the drop-down menu.
    ** In the profile panel that opens, click on the button with three dots (...) (More).
    ** In the menu that appears, click Copy member ID.
    ** Paste this ID in `MY_SLACK_ID` variable of the `.env`
. **Force Refresh Slack Client**:
  * Open your desktop Slack application and press `Ctrl + R` (Windows) or `Cmd + R` (Mac) +
    to re-read rights and unblock the app's messaging interface.
. **Locate the App**:
  * Open your desktop Slack application
  * In the Slack left sidebar under *Apps*
    ** Find app `slack-reactions-notifier`
       *** if the app is absent then
           **** Click + Add apps
           **** Find and add `slack-reactions-notifier`
    ** Open the app's direct chat.
    ** Send any message to verify text input is fully unlocked.
. **Test the Handler**:
  * Run your container with slack reactions notifier script.
  * Post a message inside the bot's direct chat or any channel you are a member of.
  * Add an emoji reaction.
  * A notification message will arrive from the bot in your personal chat +
    with this bot in the *Apps* section.

=== Using Docker

==== Build the image

[source,bash]
----
./docker_build.sh
----

==== Run the container

[source,bash]
----
./docker_run.sh
----

=== Local Development

==== Install dependencies

[source,bash]
----
pip install -r requirements.txt
----
(Note: It is recommended to use `uv` or `pip` with `pyproject.toml`)

==== Run the application

[source,bash]
----
python -m app.slack_reaction_notifier
----
